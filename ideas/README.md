# Blog Ideas

완성된 초안이 되기 전의 생각을 가볍게 기록하는 공간입니다.

`template.md`를 복사해 `ideas/<주제>.md`로 만들고, 알고 있는 내용만 간단히
적으면 됩니다. 모든 항목을 채울 필요는 없으며 frontmatter도 사용하지 않습니다.
나중에 AI와 작업할 때 이 메모를 바탕으로 `posts/`의 정식 원고를 작성합니다.

## 작성 원칙

- 핵심 아이디어를 한두 문장으로 적습니다.
- 꼭 다루고 싶은 내용을 bullet point로 남깁니다.
- 코드, 링크, 경험담 등 참고할 재료가 있으면 함께 붙여 둡니다.
- 확실하지 않거나 추가 조사가 필요한 내용은 질문으로 적어도 됩니다.
